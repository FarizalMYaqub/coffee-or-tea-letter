A. That is the whole entry: exactly one letter, standing for coffee.

Tea waits to be asked. Coffee shows up. It is the drink that arrives first in the morning — loud, hot, unapologetic — and turns a person on before the day has even started. Tea soothes; coffee ignites. And A is the first letter, the first answer, the one that shows up first, which is exactly what coffee does. The choice is vivid because it is a jolt, funny because it refuses to be polite about it, and true because nobody who drinks coffee in the morning is pretending. This program writes the letter to `/output/entry.txt` for the judge, after checking it is exactly one letter, A or B, naming the drink it stands for.

## Run

```sh
python3 main.py
```
